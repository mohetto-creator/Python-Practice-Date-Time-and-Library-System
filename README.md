# Python Practice: Date Time and Library System

This repository contains two introductory Python assignments completed in Jupyter notebooks.

## Assignment notebooks

- **Date, Time, and Datetime:** Exercises using Python's built-in modules to retrieve, format, and modify date and time values.
- **Library Management System:** A basic interactive program for searching and maintaining book records, including issuing and returning books.

## Concepts used

Functions, lists, dictionaries, loops, conditional logic, and Python's standard date/time modules.

## Requirements

Python 3 and Jupyter Notebook or JupyterLab.

## Run

Open a notebook in Jupyter and execute its cells in order. The library program keeps its sample records in memory while it runs.
